# Y Supplier Clipboard

Поточний реліз: **2.8.2** — [зміни та інструкція оновлення](docs/RELEASE_2.8.2.md).

Автономне розширення Chrome/Edge (Manifest V3), яке за `Ctrl+Shift+Y` отримує з відкритої картки товару постачальника, артикул і назву, формує CAD-сумісний рядок та записує його в буфер обміну.

## Встановлення

1. Відкрийте `chrome://extensions` (або `edge://extensions`).
2. Увімкніть режим розробника та натисніть **Load unpacked / Завантажити розпаковане**.
3. Виберіть цю папку: `Y Supplier Clipboard — Universal Marketplace Parser`.
4. За потреби змініть гарячу клавішу в `chrome://extensions/shortcuts`.

## Використання

Інтерфейс підтримує українську (UA, за замовчуванням), англійську (ENG), російську (RU), німецьку (DE · Deutsch), польську (PL · Polski), естонську (ET · Eesti) та латиську (LV · Latviešu). Розгорніть спільну секцію **Налаштування**: перемикач **Мова інтерфейсу** розташований першим, над вкладеними секціями. Вибір автоматично зберігається локально. Перемикання не змінює назви, артикули, одиниці, чорний список чи поточні виправлення товару. Опис на картці розширення та назва команди гарячої клавіші вибираються браузером за мовою Chrome/Edge (uk/en/ru/de/pl/et/lv); для інших мов використовується англійська. Перемикач мови панелі на опис у браузері не впливає.

Переклади панелі зберігаються в окремих UTF-8 JSON-файлах `ui/locales/<мова>.json` зі сталими ключами. Їх можна редагувати без зміни коду інтерфейсу. [Інструкція для перекладачів](ui/locales/README.md). Словники читаються з розширення один раз на сторінку; після редагування перезавантажте розширення й сторінку. У версії **2.7.0** додано чотири нові мови та файлові словники.

На картці товару натисніть `Ctrl+Shift+Y`. Розширення спочатку читає JSON-LD Product, microdata/OG та загальні DOM-підказки. Якщо воно впевнено знайшло назву й один артикул, результат відразу копіюється. Якщо даних бракує або є кілька SKU, відкривається конфігуратор.

У конфігураторі поле **Постачальник** автоматично зберігає введену назву, наприклад `SIRIUS`, для всіх профілів цього домену. Кнопку збереження для цього натискати не потрібно. Правила вилучення зберігаються окремо через **Зберегти профіль**. Верхні поля артикула й назви редагують лише поточне копіювання; зміна тексту результату не переписує CSS-правило автоматично. Кнопка **Закрити** не скасовує вже збережену назву постачальника.

## Налаштування нового сайту

Щоб виправити вже розпізнаний товар, натисніть іконку **Y Supplier Clipboard** на панелі розширень браузера: перше натискання відкриває конфігуратор, повторне копіює поточний результат із вашими виправленнями та закриває панель після успішного копіювання. У разі помилки панель залишається відкритою. Повторне натискання не зберігає правила — для цього використовуйте **Зберегти профіль**. Гаряча клавіша залишається командою копіювання. Якщо SKU з метаданих відрізняється від видимого «Артикул: …», автоматичне копіювання зупиняється й пропонується вибір.

Ціну можна вибрати помаранчевим курсором або ввести вручну (`9.59`, `9,59`, `€9.59`). Курсор читає також атрибути вибраного елемента та його дочірніх елементів; вибір поля зберігає ручні виправлення інших полів. Порожня ціна не блокує копіювання: призначена комірка ціни залишається порожньою. Непорожню ціну з некоректним числовим форматом потрібно виправити або очистити.

Якщо для звичайного товару сайт не надає одиниці виміру, поле автоматично отримує `шт.`. Знайдена на сайті або введена користувачем одиниця має пріоритет. Для режимів листа та хлиста автоматична підстановка `шт.` не застосовується.

Поле **Валюта** визначається окремо від числової ціни: з метаданих сайту або позначення біля ціни (`€` / `євро` → `EUR`, `грн` → `UAH`, `zł` → `PLN`, `Kč` → `CZK`). Підтримуються також коди валют, зокрема `SEK`, `NOK`, `DKK`, `ISK`. Неоднозначні `$` та `kr` не визначають країну автоматично. Валюту можна вписати вручну; ручне виправлення зберігається при виборі ціни курсором. У стилі Excel доступне окреме поле **Валюта**. Невідома або порожня валюта не блокує копіювання; поточні схеми стовпців не змінюються.

1. Відкрийте картку товару та викличте гарячу клавішу.
2. Біля «Артикул» або «Назва» натисніть **Вибрати на сторінці**.
3. Наведіть курсор на потрібний елемент та клацніть. Обирач віддає перевагу `id`, `data-*`, `itemprop` і семантичним атрибутам.
4. Перевірте попередній рядок, за потреби відредагуйте селектор і збережіть профіль.

Профілі зберігаються лише у `chrome.storage.local`. Один домен може мати кілька профілів: задайте `urlPattern` у збереженому JSON (наприклад, для окремого типу картки).

## Чорний список зайвого тексту

Розгорніть **Чорний список: прибрати зайвий текст** та вставте небажаний підпис, наприклад `Код товара:`. Кожен текст — на окремому рядку. Записи автоматично зберігаються для всіх профілів поточного домену та видаляються з розпізнаних полів. Збіг буквальний, з урахуванням регістру; символи на кшталт дужок і крапок не є командами. Щоб скасувати очищення, видаліть відповідний рядок зі списку. Інші домени не змінюються. Не додавайте сам артикул чи корисні частини назви. Максимум 100 записів по 200 символів.

## Ціна та копіювання для Excel

Поруч із верхнім прев'ю є іконка **Скопіювати результат**. Це незалежна швидка відповідь: постачальник, артикул і назва одним рядком, зі сталим базовим форматуванням. Стиль, ціна, фото, розміри та прапорці форматування експорту на неї не впливають; панель після копіювання залишається відкритою. Налаштований експорт має окреме прев'ю біля стилю та нижню кнопку **Скопіювати**.

Стилі працюють як стек: вибраний стиль стає крайнім і поточним, редактор змінює саме його. Дублювання створює новий поточний стиль із назвою `Копія Excel`; якщо назва вже зайнята, додається номер у дужках. Назва копії одразу виділяється для редагування. Видалення прибирає поточний стиль із комбобокса й повертає попередній. Назва автоматично зберігається після завершення редагування; однакові назви отримують унікальний номер.

Список **Стиль роботи** містить збережені схеми буфера для Excel, CAD та інших програм, що приймають текст із роздільниками. При першому запуску створюються **AVC / CAD** (одна готова назва) та **Excel** зі старою схемою. Стилі спільні для всіх сайтів і зберігаються локально. Кожен має власні поля A–Z, роздільник Tab, Enter або довільний ASCII-код, режим формули IMAGE та прапорці форматування назви. Вибір стилю не скидає уточнені дані товару; правила отримання полів і режим листа/хлиста залишаються в профілі постачальника.

Натисніть **✎** поруч зі списком для редактора стилю. Це одна картка: назва, дії зі стилем, роздільник, конструктор полів і формула IMAGE. Три команди розташовані в один ряд: **Дублювати**, **Скинути**, **Видалити**. Скидання переводить усі 26 комірок поточного стилю в «Не чіпати», зберігаючи назву, роздільник та інші налаштування. Для нового чистого стилю дублюйте поточний, перейменуйте його та скиньте комірки. Принаймні один стиль завжди залишається. Налаштування експорту й форматування автоматично записуються у вибраний стиль; **Зберегти профіль** потрібне для правил сайту. Експорт JSON профілів постачальників не містить бібліотеку стилів.

Панель показує ціну й одиницю виміру. Автоматичний пошук використовує JSON-LD offers, microdata та елементи ціни сторінки. Якщо даних немає або знайдено кілька варіантів, перевірте значення вручну або натисніть **Вибрати ціну на сторінці** / **Вибрати одиницю**. Правила цих полів зберігаються через **Зберегти профіль**. Одиниця не підставляється навмання.

Кнопка **Скопіювати** приймає показані ціну й одиницю, навіть якщо знайдено альтернативні варіанти. Повторно вибирати правильне значення не потрібно; списки залишаються для виправлення. За наявності альтернатив швидке копіювання відкриває панель для перегляду. Порожня одиниця, некоректна ціна та непідтверджений розмір листа в Excel і далі блокують копіювання.

Виберіть стиль і відкрийте його редактор. У кожній комірці конструктора A–Z є список: **Не чіпати**, повна назва, постачальник, артикул, назва товару, одиниця з розміром або без розміру, ціна, довжина (м), ширина (м), товщина (мм), розмір листа (м) та **Об’єднати через пробіл**. Поставте цей пункт між двома полями, щоб створити одну комірку: наприклад, `Постачальник` → `Об’єднати через пробіл` → `Артикул` дасть `VIYAR 190218`. Прокрутіть схему вправо для доступу до дальніх стовпців. Поля можна повторювати, вибирати лише потрібні й розміщувати в будь-якому порядку. Схема зберігається автоматично у вибраному стилі; стара схема переноситься без зміни стовпців.

Повна назва враховує прапорці включення полів, CAD-форматування та товщину листа. Окремі складові вибираються незалежно від прапорців повної назви; «Назва товару» — лише назва без постачальника, артикула та доданої товщини. Ціна копіюється без валюти, з десятковою комою для українського Excel. Розміри в окремих стовпцях теж мають десяткову кому. Для них увімкніть режим плитних матеріалів та уточніть відповідні значення. Для копіювання потрібні лише призначені поля: якщо ціна чи одиниця не вибрані, їхня відсутність не заважає. При «Не чіпати» у всіх стовпцях копіювання заблоковане.

За замовчуванням готова назва вставляється в **B (2)**, одиниця в **E (5)**, ціна в **F (6)**. Стовпці **C і D не копіюються**, щоб зберегти кількість та інші дані. Звичайний буфер не може вказати Excel пропустити комірки під час одного Ctrl+V, тому розширення ділить дані на суміжні блоки без порожніх заповнювачів:

1. Натисніть **Скопіювати → B** та вставте у B потрібного рядка в Excel.
2. Поверніться до розширення, натисніть **Скопіювати → E:F** та вставте у E **того самого рядка**. Після другого копіювання панель закривається.

Кнопка розширення й Ctrl+Shift+Y також копіюють перший блок. Повторне натискання іконки відкритої панелі копіює наступний. Розширення не бачить Excel і не перевіряє, чи ви вже вставили блок: виберіть зазначений стовпець і рядок самостійно. Якщо всі три призначені стовпці суміжні (наприклад B:C:D), буде один блок і одне вставлення. Для CAD-рядка виберіть або створіть стиль з одним полем «Повна назва» і роздільником «Пробіл».

У конструкторі Excel також доступне поле **URL поточної сторінки**. Воно вставляє повну адресу активної сторінки товару, включно з параметрами та фрагментом після `#`, у вибраний стовпець. Адреса береться безпосередньо під час копіювання; правила форматування назви та чорний список її не змінюють.

Поле **URL зображення товару** вставляє посилання на головне зображення, автоматично знайдене в JSON-LD або, якщо JSON-LD не містить фото, в `og:image`. Пункт **Зображення =IMAGE("URL")** вставляє те саме посилання як формулу Excel. Якщо сайт віддає інший формат, відкрийте **Форматування та правила отримання полів** і для цього поля виберіть CSS-елемент та атрибут `src`, `data-src` або аналогічний; збережіть профіль. Коли знайдено кілька зображень, у панелі є стрілки для циклічного вибору потрібного; вибрана картинка дуже прозоро показується фоном цієї ж панелі та саме її URL копіюється до Excel. Помаранчевий курсор поруч дає змогу вказати правильне зображення безпосередньо на сторінці; правило `src` збережеться разом із профілем. Розширення не завантажує, не перейменовує та не зберігає файли зображень.

### Tab / Enter

У редакторі стилю є список **Роздільник**: **Пробіл** формує текст в одну комірку, **Tab** (стартовий варіант нового стилю) — текст в один рядок, **Enter** — текст в один стовпчик, а **Користувацький ASCII-код** дозволяє вказати будь-який код від 1 до 127 (наприклад, `59` для `;`). Режим зберігається автоматично. Вставляйте у вибрану комірку, не під час її редагування.

У вертикальному режимі ті самі позиції конструктора задають рядки 1–26 замість стовпців A–Z. Пропуски залишаються захищеними: кожна група сусідніх рядків копіюється окремою сесією. Для тестування приймача AVC розмістіть усі потрібні поля поспіль, щоб отримати один блок; підтримку роздільників самою панеллю AVC ще не підтверджено.

## Розміри плитних матеріалів

Для матеріалів у хлистах (профілів, рейок, труб тощо) увімкніть **Хлист — довжина хлиста** замість режиму листа. Ці режими взаємовиключні. У хлиста вводиться або вибирається на сторінці лише довжина; ширина й товщина приховані. Для Excel підтвердьте довжину: одиниця з розміром матиме вигляд `пог.м (5,95)` для 5950 мм. Назва одиниці залишається вашою, а довжина у дужках завжди в метрах. Режим і правило довжини зберігаються через **Зберегти профіль**; для CAD підтвердження не потрібне.

Вибір значень на сторінці запускається маленькою кнопкою із **помаранчевим значком курсора** праворуч усередині відповідного поля: артикул, назва, ціна, одиниця, довжина, ширина та товщина. Курсор спрямований ліворуч угору — у бік сторінки. При наведенні показується підказка; кнопки доступні також з клавіатури. Окремих великих кнопок під полями немає.

Увімкніть **Плитний матеріал — розмір листа**. Довжину й ширину можна отримати з підписаних характеристик сторінки або JSON-LD, вибрати кнопками на сторінці чи ввести вручну. За замовчуванням вводьте міліметри; для введення в метрах змініть одиниці. Явні суфікси `мм` / `м` мають пріоритет. Товщина та висота не використовуються як розміри листа.

Для Excel натисніть **Підтвердити розмір** перед копіюванням кожного товару. Зміна розміру чи одиниці товару скасовує підтвердження. Для Excel одиниця стає, наприклад, `лист (2,8*2,07)` для листа 2800 × 2070 мм; назва та CAD-рядок не змінюються, коми в розмірі зберігаються. Для CAD підтвердження розміру, ціна та одиниця не потрібні, навіть якщо режим плитних матеріалів увімкнений. **Зберегти профіль** зберігає режим, одиниці введення й правила вибору елементів, але не разові ручні розміри чи підтвердження.

Поле **Товщина, мм** розташоване поруч з одиницями введення розмірів. Товщина визначається з підписаних характеристик, JSON-LD або елемента, вибраного кнопкою з помаранчевим курсором; її можна виправити вручну. Значення показується в міліметрах і додається до повної назви без позначення `мм`: `VIYAR 33943 ДСП … - 18`. Це працює і для CAD, і для Excel, лише в режимі плитних матеріалів; одиниця `лист (2,8*2,07)` не змінюється. Правило вибору товщини зберігається разом із профілем.

## Імпорт / експорт профілів

Під списком доменів першою показується основна кнопка **Відкрити** поруч із назвою постачальника. Увімкнення/вимкнення, клонування, видалення профілів та домену перенесені в нижній згорнутий розділ **Службові дії та резервна копія**; імпорт і експорт — у самому його кінці.

У розділі **Профілі та резервна копія** показано лістбокс **Усі профільовані домени**. Він містить усі домени зі збереженими профілями, включно з вимкненими; число в дужках — кількість профілів домену. Виберіть домен, щоб переглянути його профілі, увімкнути/вимкнути або видалити окремий профіль.

Профіль запам’ятовує **останню сторінку використання**: при відкритті розширення для збереженого профілю, після успішного копіювання та при збереженні профілю. Для нового постачальника успішне копіювання також створює запис у довіднику. Адреса показується під назвою профілю й переноситься через експорт/імпорт JSON. Оновлення адреси існуючого профілю не зберігає незбережені правки його правил.

**Відкрити** активує саме вибраний профіль і переводить поточну вкладку на його останню сторінку. Вимкнений профіль при явному виборі цієї кнопки стає увімкненим. Для старого профілю без збереженої адреси відкривається головна сторінка домену. Після переходу можна викликати розширення звичайним способом. Дозволені лише HTTP/HTTPS-адреси того самого домену; адреси інших доменів, локальних файлів або зі скриптами не використовуються.

Кнопка **Видалити домен та його профілі** видаляє всі профілі лише вибраного домену після підтвердження. Інші домени та глобальна компоновка Excel не змінюються. Перед видаленням за потреби зробіть **Експорт JSON**: для відновлення потрібен раніше збережений файл. Видалення профілів поточного сайту перезавантажує панель із рештою збережених правил або стандартними налаштуваннями.

Пункт **Any Text** у конструкторі дозволяє набрати власний текст прямо в комірці. Текст зберігається у вибраному стилі, підтримує об’єднання через пробіл та копіюється разом з іншими полями. Стрілка праворуч повертає до списку полів. Комірки мають ширину 67 px.

У редакторі стилю кнопка **Експорт стилю** зберігає поточний стиль у текстовий файл `Назва.ysc-style.json` через діалог вибору місця збереження. Файл містить назву, роздільник, ASCII-код, 26 комірок (включно з власним текстом) та правила форматування. **Імпорт стилю** читає вибраний файл і додає його в локальний список, одразу вибираючи імпортований стиль. Якщо назва зайнята, додається «Копія» та за потреби номер. Початковий файл залишається на місці. Профілі доменів, товарні дані, мова, прозорість і колір акцентів до файлу стилю не входять.

У конфігураторі натисніть **Експорт JSON**, щоб зберегти всі локальні профілі, або **Імпорт JSON**, щоб завантажити масив профілів. Файл не містить глобальні стилі роботи: вони зберігаються окремо локально. Поточна схема профілів — `schemaVersion: 1`; під час імпорту записи нормалізуються до цієї версії.

Стабільний код: `main`, тег `v2.7.0`. Майбутні правки: `develop`. [Зміни релізу 2.7.0](docs/RELEASE_2.7.0.md) та [попереднього 2.0.0](docs/RELEASE_2.0.0.md). Для передачі колегам виконайте `powershell -ExecutionPolicy Bypass -File scripts/package-release.ps1` у `develop`: ZIP у `dist/` містить файли розширення, README, MIT та довідкові документи; без тестів, вихідних зображень, особистого скриншота та `.git`. Після кожної завершеної зміни поведінки або інтерфейсу підвищуйте версію розширення в `manifest.json` та синхронно в `package.json`: patch для виправлень і косметики, minor для нових можливостей. `manifest_version` і версія схеми профілів від цього не змінюються. Поточний реліз — **2.7.0** (14.10.2026).
