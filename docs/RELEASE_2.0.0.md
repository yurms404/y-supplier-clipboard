# Y Supplier Clipboard 2.0.0

Production release · 14.10.2026 · Chrome / Edge · Manifest V3

## Нове

- Незалежне швидке копіювання постачальника, артикула та назви кнопкою біля верхнього прев’ю.
- Іменовані стилі роботи з автоматичним збереженням, дублюванням, перейменуванням, скиданням комірок та видаленням поточного стилю.
- Окремий експорт одного стилю в читабельний `.ysc-style.json` з діалогом збереження. Імпорт читає файл на місці, додає й вибирає стиль з унікальною назвою.
- Конструктор 26 комірок шириною 67 px, назви у 2–3 рядки та одна рамка вибору. Пункт **Any Text** дозволяє вводити власний текст прямо в комірці.
- Роздільники Tab, Enter, пробіл і користувацький ASCII-код. Оператор «Об’єднати через пробіл» працює з полями та власним текстом; у режимі пробілу додає погоджені три пробіли.
- URL картинки та `=IMAGE("URL")` як окремі значення комірок.
- Розпізнавання галереї товару, перемикання картинок, ручний вибір на сторінці та фонове прев’ю в обмеженій зоні.
- Глобальні налаштування прозорості й кольору акцентів для рамок, тексту, курсорчиків і повзунка. Компактні налаштування, світла й темна тема.
- Спрощене керування профілями доменів та резервними копіями.

## Оновлення та встановлення

Завантажте `y-supplier-clipboard-2.0.0.zip`, розпакуйте й виберіть папку через **Load unpacked / Завантажити розпаковане** у `chrome://extensions` або `edge://extensions`.

Для оновлення наявного встановлення замініть файли у його папці, перезавантажте розширення та сторінки товарів. Профілі залишаються у схемі `schemaVersion: 1`; попередні налаштування Excel переносяться у стилі роботи. Перед оновленням можна зберегти резервну копію профілів кнопкою **Експорт JSON**.

Новий дозвіл `downloads` потрібен для експорту стилю через діалог збереження. Імпорт файлу виконується локально. ZIP містить розширення, README, ліцензію MIT і документацію; тести та прототипи залишаються у репозиторії розробки.

## Перевірки

Автоматизовані тести парсера, форматування, Excel, профілів, мов, розмірів, панелі й довідки та синтаксична перевірка JavaScript. Перевірено збереження й імпорт стилів, власний текст, роздільники та відсутність хибної картинки з порожнього URL.
