# Y Supplier Clipboard 2.7.0 — 7 мов

Production release · 14.10.2026 · Chrome / Edge · Manifest V3

## Мови

До української, англійської та російської додано:

- **DE · Deutsch** — німецька;
- **PL · Polski** — польська;
- **ET · Eesti** — естонська;
- **LV · Latviešu** — латиська, мова Латвії.

Усі сім мов доступні в **Налаштування → Мова інтерфейсу**. Вибір зберігається локально. Опис розширення й гаряча клавіша також мають сім браузерних локалізацій. Дані товарів, назви стилів і власний текст залишаються такими, як їх увів користувач.

## Словники

213 повідомлень кожної мови винесено в окремі UTF-8 JSON-файли `ui/locales/<код>.json` зі сталими ключами. Переклади можна редагувати без зміни коду інтерфейсу. Додано інструкцію для перекладачів у `ui/locales/README.md`.

Словники завантажуються локально з розширення один раз на сторінку. За відсутності перекладу використовується англійський текст, потім український. Перемикання зберігає поточні виправлення товару та налаштування стилю.

## Встановлення й оновлення

Завантажте `y-supplier-clipboard-2.7.0.zip`, розпакуйте та завантажте папку через **Load unpacked / Завантажити розпаковане** у `chrome://extensions` або `edge://extensions`.

Для оновлення наявного встановлення замініть файли в його папці, перезавантажте розширення й відкриті сторінки товарів. Збережені профілі та стилі підтримуються; нові дозволи не додаються. Для резервної копії використовуйте **Експорт JSON** для профілів та **Експорт стилю** для окремих стилів.

## Перевірки

Усі автоматизовані тести та синтаксичні перевірки пройдено. Перевірено повноту семи словників, параметри повідомлень, резервний переклад, кешування, збереження вибраної мови та незмінність товарних даних. У ZIP включено всі словники панелі й браузера та інструкції.
