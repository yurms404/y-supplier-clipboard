# Y Supplier Clipboard 3.1.0

**18 жовтня 2026 року.** Готовий експорт картки товару у властивості A>V>C>. Розширення отримало вбудований стиль **AVC Properties**, який формує рядок із 14 значень для прямого імпорту в панель властивостей A>V>C>, і п'ять нових полів, яких раніше бракувало: призначення, категорія, опис, густина та упаковка.

## Готовий стиль AVC Properties

Раніше єдиний стиль із назвою AVC містив лише одне поле — повну назву. Імпорт властивостей A>V>C> потребує 14 полів у сталому порядку, тому з'явився окремий стиль.

| Комірка | Поле A>V>C> | Джерело |
| --- | --- | --- |
| A | Назва | **Назва товару** |
| B | Використання | **Призначення** |
| C | Вид / тип / сорт | **Категорія** |
| D | Опис | **Опис** |
| E | Довжина | довжина листа |
| F | Ширина | ширина листа |
| G | Товщина | товщина листа |
| H | Постачальник | постачальник |
| I | Артикул | артикул |
| J | Ціна | ціна за м² або за пог.м |
| K | Густина / вага | **Вага / густина** |
| L | Упаковка | **Упаковка** |
| M | Гіперпосилання | URL поточної сторінки |
| N | Шлях до зображення | URL зображення товару |

Усі 14 полів стоять поспіль, тому звичайний буфер дає одну сесію копіювання без порожніх заповнювачів — саме те, що потрібно приймачу.

Стиль створюється при першому запуску й **додається до вже налаштованих встановлень**, якщо його немає в списку. Решта стилів не змінюється.

## П'ять нових полів

- **Призначення** — список із шести значень A>V>C> (`Volume`, `Sheet`, `Rod`, `Cover`, `Banding`, `Item`), порожнього пункту та **Не чіпати**, яке копіюється як `-`. Автоматично підставляються `Sheet` або `Rod` за режимом листа/хлиста та `Item` для решти товарів. Ручний вибір має приоритет.
- **Категорія**, **Опис**, **Вага / густина** та **Упаковка** — звичайні текстові поля.

Поля з'являються в панелі лише тоді, коли вибраний стиль використовує відповідні стовпці, тому інші стилі не отримують зайвих контролів.

Кожне поле працює двома способами: значення можна ввести вручну для конкретного товару, або задати правило вилучення зі сторінки в розділі **Форматування та правила отримання полів**. Введене вручну значення запам'ятовується для домену — наступний товар на тому самому сайті відкривається з ним.

## Ціна за одиницю площі або довжини

Поле **Ціна за м² / пог.м** перераховує ціну з картки автоматично:

- за квадратний метр — для плитних матеріалів і покриттів (призначення `Sheet`, `Cover`);
- за погонний метр — для хлиста й кромки (призначення `Rod`, `Banding`);
- без змін — для об'ємних і штучних позицій, а також тоді, коли розмірів немає або вони непридатні.

## Числа, одиниці та порожні розміри

Чотири прапорці працюють окремо для кожного стилю:

- **Крапка в числах** — десяткова крапка замість коми, як вимагає A>V>C>.
- **Одиниці біля розмірів** — `2800mm`, `16mm`; приймач сам перерахує їх в одиниці креслення.
- **Розміри в міліметрах** — довжина й ширина в міліметрах замість метрів.
- **Дозволити порожні розміри** — знімає вимогу підтвердити розмір листа й дозволяє копіювати рядок без розмірів.

Прапорці зберігаються у стилі та переносяться експортом стилю. Український Excel зберігає кому, якщо **Крапка в числах** вимкнена.

## Десяткова кома та описи

Одинарний дефіс `-` копіюється як є: приймач читає його як «залишити значення без змін». Довші тексти, що починаються з `-`, `=`, `+` або `@`, як і раніше отримують апостроф для Excel. Опис товару зберігає коми, а постачальник — регістр, як його введено.

## Конструктор стовпців

У списку полів кожної комірки A–Z додано **опис**, **ціну за м² або пог.м**, **призначення**, **категорію**, **вагу / густину** та **упаковку**. Наявні схеми не змінюються: старі стилі зберігають свої стовпці.

## Встановлення й оновлення

1. Завантажте **`y-supplier-clipboard-3.1.0.zip`** у розділі **Assets** цього релізу.
2. Розпакуйте ZIP у постійну папку.
3. У Chrome відкрийте `chrome://extensions`, в Edge — `edge://extensions`, і ввімкніть режим розробника.
4. Для оновлення замініть файли в тій самій папці, звідки вже завантажене розширення, і натисніть **Перезавантажити** на його картці. Не видаляйте встановлене розширення, якщо хочете зберегти локальні дані.
5. **Оновіть відкриті сторінки постачальників.** Основна гаряча клавіша — `Ctrl+Shift+Y`.

Версії `manifest.json` і `package.json` синхронізовані: **3.1.0**. `manifest_version` залишається **3**, схема профілів не змінюється, нових дозволів не додано.

## Що ще слід перевірити

Стиль налаштований за описом формату A>V>C> та за зразком рядків, наданим користувачем. **Прийом рядка живою панеллю A>V>C> в AutoCAD або BricsCAD ще не перевірявся.** Перед копіюванням партії перевірте один товар кожного типу — плитний, хлистовий і штучний.

## Перевірки

До релізу входять автоматизовані перевірки форматування, парсингу, схем копіювання, локалізації, панелі та окремий набір перевірок палітри A>V>C>: склад і порядок 14 полів, одна сесія копіювання, крапка в числах, одиниці біля розмірів, перерахунок ціни за м² та за погонний метр, збереження коми в описі, захисний апостроф і значення `-`. Це перевірки коду та імітованих браузерних взаємодій; вони не є сертифікацією для кожної версії Chrome, Edge, AutoCAD або BricsCAD.
