# Y Supplier Clipboard 3.1.4

**18 жовтня 2026 року.** Тип позиції керує розмірами. Прапорці **Плитний матеріал — розмір листа** та **Хлист — довжина хлиста** прибрано: вони дублювали **Призначення** і могли йому суперечити.

## Що було видно на сторінці

Панель уже показувала **Призначення: Автоматично (Sheet)**, але прапорець **Плитний матеріал** лишався вимкненим. Через це розміри з характеристик не читалися, комірки E, F і G були порожні, а в J їхала ціна за цілий лист (`15371.7`) замість ціни за м². Два контроли про одне й те саме неминуче розходилися.

## Як тепер

Тип позиції — єдине керування розмірами, а прапорців немає:

| Тип | Що читається | Ціна J |
| --- | --- | --- |
| `Sheet` | довжина, ширина, товщина | за м² |
| `Rod` | лише довжина | за погонний метр |
| `Cover` | довжина, ширина, товщина | за м² |
| `Banding` | лише довжина | за погонний метр |
| `Volume`, `Item` | розміри не читаються зовсім | ціна з картки |

Тип визначається з одиниці товару (`лист`, `м²` → `Sheet`; `пог.м`, `хлист` → `Rod`), а вибір у списку **Призначення** запам'ятовується для домену. Повернення до **Автоматично (Тип)** знову віддає рішення одиниці. Рядок **Одиниця товару: … → …** під списком показує, з чого саме взято тип.

Список стоїть у розділі **Властивості A>V>C>**, якщо стиль друкує комірку B. Для стилю без цього стовпця той самий список показується над полями розмірів, щоб їх можна було ввімкнути для CAD і для довільних стилів. Кожне значення підписано мовою інтерфейсу: `Sheet — Листовий матеріал`, `Rod — Погонаж / прут` тощо (сім мов).

## Що змінилося під капотом

- `format.sheet` і `format.sheetRod` більше не окремі налаштування, а похідні від типу: `Sheet` → лист, `Rod` → хлист. Парсер ніде не читає їх як вхідні дані, тому застарілий прапорець не може вимкнути розміри.
- Одиниця товару не вигадується для типу `Sheet`/`Rod`: якщо магазин не показав одиницю, поле лишається порожнім, а не «шт.».
- Правило поля `usage` зі старих версій з порожнім ручним значенням автоматично стає автоматичним, щоб не копіювати порожню комірку B.
- Розміри перечитуються одразу при зміні типу, а підтвердження розміру скидається — так само, як при зміні довжини, ширини чи одиниці.

## Встановлення й оновлення

1. Завантажте **`y-supplier-clipboard-3.1.4.zip`** у розділі **Assets** цього релізу.
2. Розпакуйте ZIP у постійну папку.
3. У Chrome відкрийте `chrome://extensions`, в Edge — `edge://extensions`, і ввімкніть режим розробника.
4. Для оновлення замініть файли в тій самій папці, звідки вже завантажене розширення, і натисніть **Перезавантажити** на його картці. Не видаляйте встановлене розширення, якщо хочете зберегти локальні дані.
5. **Оновіть відкриті сторінки постачальників.** Основна гаряча клавіша — `Ctrl+Shift+Y`.

Версії `manifest.json` і `package.json` синхронізовані: **3.1.4**. `manifest_version` залишається **3**, схема профілів не змінюється, нових дозволів не додано.

## Що перевірити далі

Той самий товар, на якому була розбіжність: якщо одиниця товару містить `лист` (або `м²`), тип стає `Sheet`, поля довжини й ширини з'являються самі, а J рахується за м². Для сторінки без одиниці виберіть `Sheet` чи `Rod` у списку один раз — вибір запам'ятається для домену.

**Прийом рядка живою панеллю A>V>C> в AutoCAD або BricsCAD усе ще не перевірено.** До такого тесту порядок і склад 14 полів A–N не змінюються.

## Перевірки

Оновлено набори тестів парсера, розмірів, палітри та панелі: тип керує розмірами (`Sheet` — довжина й ширина, `Rod` — лише довжина, `Item` і `Volume` — без розмірів), застарілий `format.sheet` більше не замінює тип, у списку вісім пунктів із перекладеними назвами, прапорців листа/хлиста в панелі немає. Усі набори тестів і `npm run check` проходять.
