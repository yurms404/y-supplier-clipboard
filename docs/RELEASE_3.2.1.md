# 3.2.1 — копіювання в Chrome 109–115

- Прибрано безумовний виклик `chrome.runtime.getContexts()`, через який копіювання завершувалося помилкою у старих Chromium.
- Для Chrome 109–115 прихований документ перевіряється через `clients.matchAll()` за точною адресою; сучасний шлях збережено.
- Одночасні запити використовують спільне створення документа; після невдалого створення можна повторити спробу.
- Мінімальна версія Chrome у маніфесті — 109. Для браузерів без `chrome.offscreen` додано зрозуміле повідомлення.
- Додано регресійні тести старого і нового API, повторних запитів, помилок та DOM-копіювання.

Перевірено `npm test` і `npm run check`. Сумісність зі старим API перевірена імітацією; реальна Windows 8.1 / Chrome 109 потребує окремої перевірки.

Після оновлення перезавантажте розширення та сторінку товару.
