# 3.3.0 — копіювання окремих полів

- У полях «Артикул», «Назва товару» та «Ціна» після кнопки вибору зі сторінки додано компактну кнопку копіювання.
- Копіюється поточний текст поля, включно з ручними виправленнями, без формування CAD/Excel-рядка чи перевірки інших полів.
- Кнопки використовують однакову контурну іконку двох аркушів; верхня кнопка копіювання результату отримала ту саму іконку.
- Підказки перекладені наявними словниками; кнопки доступні через Tab та Enter.
- Включено виправлення з 3.2.1: резервний шлях копіювання для Chromium 109–115 без `runtime.getContexts()`. Мінімальна версія Chrome — 109.

Перевірено `npm test`, `npm run check`, браузерну перевірку `npm run test:field-copy-ui`: копіювання поточних значень, клавіатуру, розташування кнопок без перекриття та панель при ширині вікна 390 px.
Старий API перевірено імітацією; перевірка на справжній Windows 8.1 / Chrome 109 ще потрібна.

Після розпакування оновлення перезавантажте розширення та сторінку товару. Налаштування профілів зберігаються при оновленні тієї самої інсталяції.
