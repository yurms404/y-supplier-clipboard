# Дослідження напрямків наступної версії

Дата: 13.10.2026 (доповнено 18.10.2026). Це пропозиції, не зобов'язання й не реалізовані функції. Станом на 3.1.1 реалізовано палітру A>V>C> (пункт 4 частково): вбудований стиль `AVC · 14 полів (A:N)` з 14 полями та п'ятьма новими полями.

## Схожі продукти

| Продукт / першоджерело | Документовані можливості | Що корисно запозичити |
| --- | --- | --- |
| [Web Scraper](https://webscraper.io/documentation/selectors) | Дерева селекторів, повторні елементи, керована структура результатів | Діагностика збігів правил і контроль відповідності поля товару |
| [Data Miner](https://dataminer.io/) | Готові/власні recipes, CSV/Excel, списки URL і пагінація | Бібліотека профілів постачальників; збережені набори завдань |
| [Simplescraper](https://simplescraper.io/docs/dashboard-guide) | Recipes, результати, експорт та хмарні запуски/інтеграції | Історія результатів і відділення вилучення від експорту |
| [Instant Data / Web Robots](https://webrobots.io/instantdata/) | Описані автоматичне визначення таблиці, CSV/XLSX, пагінація, infinite scroll | Збір кількох позицій перед експортом. Увага: сторінка прямо повідомляє, що Web Robots більше не володіє, не розвиває й не підтримує продукт; поточний стан нового власника не перевірено |

Це функціональні аналоги, а не повні заміни. Наше відмінне позиціонування: швидке копіювання однієї картки для меблевого CAD/Excel, розміри листа/хлиста, локальні правила та неперезаписування пропущених стовпців. Не варто перетворювати просту панель у універсальний crawler.

## Рекомендований порядок

1. **Локальна історія товарів**: останні 50–200 результатів з URL і часом; повторне копіювання, видалення та очищення. Визначити, чи зберігаємо підтверджений результат чи сирі дані. Повторна ціна позначається як історична, не як актуальна.
2. **Обмін одним профілем**: експорт лише вибраного домену/профілю, перевірка імпорту, merge без затирання решти профілів. Спільний каталог правил тільки після згоди на публікацію URL/селекторів.
3. **Діагностика полів**: джерело значення, кількість збігів CSS, попередження «правило більше не працює», запасний селектор. Все під катом, основну форму не роздувати. Після DOM-зміни ніякого мовчазного копіювання підозрілої ціни.
4. **Іменовані схеми вставки**: «CAD», «кошторис», «склад», «AVC-тест»; збереження компоновки й Tab/Enter окремо від домену. Не обіцяти, що AVC прийме кілька полів, доки не перевірено на живій програмі.
5. **Кошик вибраних товарів**: вручну додати кілька карток, прибрати дублі за доменом+артикулом, експортувати одним файлом CSV/JSON. XLSX — окреме рішення щодо залежності/типів комірок. Вставлення файлу НЕ обходить захист пропусків в існуючій Excel-базі.
6. **Ціна та матеріали**: валюта, дата ціни, ціна за лист/м² або хлист/пог.м; конвертація лише з явним напрямком і підтвердженням. Не міняти вихідну ціну непомітно.

## Пізніше, тільки за реальною потребою

- Моніторинг цін: окремо визначити зберігання, частоту, згоду користувача, дозволи сайтів і поведінку при закритому браузері. Не додавати автоматичні фонові обходи зараз.
- Приймач Excel/AVC: версійований JSON-протокол з назвами полів та цільовими позиціями; окремий модуль, а не правка 40-тисячного моноліту. Для пропусків потрібен приймач, звичайний clipboard не гарантує sparse-write.
- Firefox та магазини розширень: перевірка сумісності offscreen/clipboard, політика приватності, реальні браузерні тести, окремий процес публікації. GitHub-публікація не дорівнює Chrome Web Store/Edge Add-ons.

## Мінімальна наступна версія

Я б обрав **локальну історію + обмін одним профілем + діагностику джерел**. Це допомагає щоденній роботі й підтримці без сервера та втручання в Excel. Усі функції опційні; ніяких нових мережевих передач без явної згоди.
