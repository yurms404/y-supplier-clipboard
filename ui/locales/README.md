# Словники інтерфейсу

Один JSON-файл UTF-8 на мову: `uk`, `en`, `ru`, `de`, `pl`, `et`, `lv`.

Ключі — сталі ідентифікатори повідомлень. Змінюйте текст значень, не ключі:

```json
{
  "work_style": "Arbeitsstil",
  "save_profile": "Profil speichern",
  "accent_color": "Akzentfarbe"
}
```

Усі словники мають однаковий набір ключів. Зберігайте параметри `{value}`, `{error}`, `{target}` тощо без зміни їхніх назв. Порядок параметрів у реченні можна змінювати. `\n` означає перенесення рядка; лапки всередині тексту записуйте як `\"`.

Для нової мови скопіюйте `en.json`, перекладіть значення й додайте код та власну назву мови в список `languages` у `ui/i18n.js`. Для опису розширення і гарячої клавіші додайте `_locales/<код>/messages.json`. Перевірки: `node tests/i18n.test.js` та `node tests/language-panel.test.js`.

Словники завантажуються з файлів самого розширення один раз на сторінку. За відсутності окремого перекладу використовується англійський, потім український текст. Невідомий код мови обирає українську. Мова зберігається локально в `ysc_language`; товарні дані та власний текст не перекладаються.

Виклики інтерфейсу використовують `t("save_profile")`. Українські повідомлення з парсера, форматування та сховища підтримуються як сумісні псевдоніми — їх зіставляють із `uk.json`.
